Studify CA

Study planner for CA students. Free. Pick your device.

Android phone Your device

Download the APK, then open it to install.

Download for Android
How to install
  1. Tap the button. The APK downloads.
  2. Open the downloaded file. If Android asks, allow Install unknown apps for your browser.
  3. If Play Protect warns, tap More details then Install anyway. It shows this because the app is not on Play Store yet.

Windows laptop Your device

Download the setup file and run it.

Download for Windows
How to install
  1. Open Studify-CA-Setup.exe from your Downloads.
  2. If Windows says Windows protected your PC, click More info then Run anyway. It shows this because the installer is not signed yet.
  3. Sign in to the app. Closing the window keeps it in the tray. Right-click the tray icon to quit.

iPhone, Mac or any browser Your device

No download needed. Open the app and add it to your home screen.

Open Studify CA
Add to home screen
  1. iPhone: open in Safari, tap Share, then Add to Home Screen.
  2. Mac / PC (Chrome): click the install icon at the right of the address bar.
